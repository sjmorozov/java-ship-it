# ShipIt

Небольшое консольное приложение на Java для управления отправкой посылок.

## Возможности

- добавление посылок
- расчёт стоимости доставки
- отправка посылок
- отслеживание хрупких посылок
- хранение посылок в коробках с ограничением по весу

## Типы посылок

- `StandardParcel` — обычная посылка
- `PerishableParcel` — скоропортящаяся посылка
- `FragileParcel` — хрупкая посылка с отслеживанием

## Технологии

- Java
- Generics
- Collections
- JUnit 5

## Запуск

Запуск программы через класс `DeliveryApp`

После запуска в консоли появляется меню управления посылками.

## Учебный проект

Проект создан для практики:

- ООП
- обобщений (Generics)
- работы с коллекциями
- юнит-тестирования

## Tests

Проект содержит unit-тесты для:

- расчёта стоимости доставки
- проверки срока годности посылок
- проверки добавления посылок в коробку
